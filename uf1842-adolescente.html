Habla con el adolescente

Le hables como le hables, contesta con lo mínimo. Pero no contesta al azar: se fija en si le preguntas, si le gritas o las dos cosas a la vez. Háblale, mira qué camino sigue el programa y después constrúyelo tú siguiendo el guion.

Pone en práctica lo visto en la UF1842: B2 · condicionales, B3 · funciones, B7 · manipulación de texto, C1 · el DOM y C2 · eventos.

Prueba con:

Prueba también «¿Vienes? » con un espacio al final, «OK» o «1234». Pulsa Enter para hablar sin usar el ratón.

Lo que ocurre en el código

Al hablarle se iluminan, en orden, solo las líneas que se ejecutan. Cada tipo de frase sigue un camino distinto por la cadena de if.

function contestar() {  const frase = casilla.value.trim();  const esPregunta = frase.endsWith("?");  const esGrito = frase === frase.toUpperCase() &&                  frase !== frase.toLowerCase();  if (frase === "") {    respuesta.textContent = "Vale, pues nada.";  } else if (esPregunta && esGrito) {    respuesta.textContent = "¡Que sí, que ya voy!";  } else if (esGrito) {    respuesta.textContent = "¡Relájate!";  } else if (esPregunta) {    respuesta.textContent = "Ni idea.";  } else {    respuesta.textContent = "Lo que tú digas.";  }}

Guion de tareas

Vas a crear cuatro archivos en una misma carpeta: index.html, estilos.css, adolescente.js y la imagen adolescente.svg. Los pasos 1 a 6 construyen al adolescente con sus cuatro respuestas; los pasos 7 y 8 son la ampliación. Marca cada paso cuando lo termines.

  2. Escribe el HTML: el bocadillo, la imagen y la casilla

    Archivo: index.html

    El párrafo #respuesta será el bocadillo donde contesta el adolescente. Debajo van la imagen, una casilla de texto con su <label> y el botón «Decir». Todo lo que vamos a usar desde JavaScript lleva un id.

    <!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Habla con el adolescente</title>
  <link rel="stylesheet" href="estilos.css">
</head>
<body>
  <h1>Habla con el adolescente</h1>

  <p id="respuesta" aria-live="polite">…</p>
  <img src="adolescente.svg" alt="Un adolescente con cara de aburrimiento y unos cascos al cuello" width="200" height="220">

  <label for="frase">Dile algo</label>
  <input type="text" id="frase" autocomplete="off">
  <button id="decir">Decir</button>

  <script src="adolescente.js"></script>
</body>
</html>

    El alt de la imagen describe lo que se ve para quien no puede verla. El atributo aria-live="polite" hace que un lector de pantalla lea cada respuesta nueva (lo verás en la UF1843).

  4. Busca los elementos y haz que conteste algo

    Archivo: adolescente.js

    Guardamos en constantes la casilla, el botón y el bocadillo. Al hacer click en «Decir» leemos lo escrito con .value y, de momento, el adolescente contesta siempre lo mismo. El console.log te deja ver en la consola qué ha leído el programa.

    // 1. Buscamos los elementos de la página
const casilla = document.getElementById("frase");
const botonDecir = document.getElementById("decir");
const respuesta = document.getElementById("respuesta");

// 2. Qué pasa al pulsar «Decir»
botonDecir.addEventListener("click", function () {
  const frase = casilla.value;
  console.log("Me has dicho: " + frase);
  respuesta.textContent = "Lo que tú digas.";
});

    Guarda, abre index.html en el navegador, escribe cualquier cosa y pulsa «Decir». Pulsa F12 y mira la pestaña Consola: ahí aparece tu frase.

  5. Reconoce las preguntas

    Archivo: adolescente.js (cambia el bloque del click)

    Una frase es una pregunta si termina con ?. El método endsWith("?") lo comprueba y devuelve true o false. Guardamos ese resultado en esPregunta y con un if / else elegimos la respuesta. Sustituye el bloque del click por este:

    botonDecir.addEventListener("click", function () {
  const frase = casilla.value;
  const esPregunta = frase.endsWith("?");

  if (esPregunta) {
    respuesta.textContent = "Ni idea.";
  } else {
    respuesta.textContent = "Lo que tú digas.";
  }
});

    Solo cuenta el signo del final: el ¿ del principio no hace falta para el programa. Prueba en la consola "¿Vienes?".endsWith("?") y "Vienes".endsWith("?").

  6. Reconoce los gritos y las preguntas gritadas

    Archivo: adolescente.js (archivo completo)

    Una frase está gritada si pasarla a mayúsculas no la cambia: frase === frase.toUpperCase(). Pero eso también es cierto para «1234» o «?», que no tienen letras. Por eso pedimos una segunda condición con && («y»): que la frase sí cambie al pasarla a minúsculas, es decir, que tenga alguna letra.

    Con dos comprobaciones hay cuatro casos, y se resuelven con una cadena de else if. Este es el archivo adolescente.js completo:

    // 1. Buscamos los elementos de la página
const casilla = document.getElementById("frase");
const botonDecir = document.getElementById("decir");
const respuesta = document.getElementById("respuesta");

// 2. Qué pasa al pulsar «Decir»
botonDecir.addEventListener("click", function () {
  const frase = casilla.value;
  const esPregunta = frase.endsWith("?");
  const esGrito = frase === frase.toUpperCase() && frase !== frase.toLowerCase();

  if (esPregunta && esGrito) {
    respuesta.textContent = "¡Que sí, que ya voy!";
  } else if (esGrito) {
    respuesta.textContent = "¡Relájate!";
  } else if (esPregunta) {
    respuesta.textContent = "Ni idea.";
  } else {
    respuesta.textContent = "Lo que tú digas.";
  }
});

    El orden importa. JavaScript entra en el primer if que se cumple y se salta el resto. Si comprobaras esGrito antes que esPregunta && esGrito, una pregunta gritada entraría por el grito y nunca oirías «¡Que sí, que ya voy!». Haz la prueba cambiando el orden.

    toUpperCase() no cambia la frase original: devuelve una copia en mayúsculas. Funciona también con la ñ y las tildes: "¿ESTÁS?" === "¿estás?".toUpperCase() da true.

    Ahora pulsa «Decir» con la casilla vacía, o escribe «¿Vienes? » con un espacio al final. En los dos casos contesta «Lo que tú digas.». Lo arreglamos en la ampliación.

  7. Ampliación

    El adolescente ya contesta, pero se lía con los espacios y no sabe qué hacer cuando no le dices nada. Además, hablar con él obliga a ir al ratón cada vez.

  8. Quita los espacios y responde al silencio Ampliación

    Archivo: adolescente.js

    El método trim() quita los espacios del principio y del final de un texto. Con él, «¿Vienes? » se queda en «¿Vienes?», y una casilla con solo espacios se queda en "", el texto vacío. Cambia la línea que lee la casilla:

      const frase = casilla.value.trim();

    Después añade el silencio como primer caso de la cadena, porque si no hay frase no tiene sentido preguntarse si es una pregunta. Así queda el archivo completo:

    // 1. Buscamos los elementos de la página
const casilla = document.getElementById("frase");
const botonDecir = document.getElementById("decir");
const respuesta = document.getElementById("respuesta");

// 2. Qué pasa al pulsar «Decir»
botonDecir.addEventListener("click", function () {
  const frase = casilla.value.trim();
  const esPregunta = frase.endsWith("?");
  const esGrito = frase === frase.toUpperCase() && frase !== frase.toLowerCase();

  if (frase === "") {
    respuesta.textContent = "Vale, pues nada.";
  } else if (esPregunta && esGrito) {
    respuesta.textContent = "¡Que sí, que ya voy!";
  } else if (esGrito) {
    respuesta.textContent = "¡Relájate!";
  } else if (esPregunta) {
    respuesta.textContent = "Ni idea.";
  } else {
    respuesta.textContent = "Lo que tú digas.";
  }
});

    Compruébalo: casilla vacía, casilla con espacios y «¿Vienes? » con espacio. Las tres deben dar la respuesta correcta.

  9. Háblale con la tecla Enter Ampliación

    Archivo: adolescente.js

    Queremos que conteste tanto al pulsar «Decir» como al pulsar Enter dentro de la casilla. Para no escribir el mismo código dos veces, lo sacamos a una función con nombre, contestar, y la usamos en los dos eventos. El evento keydown salta con cada tecla, y evento.key dice cuál ha sido.

    Al final de contestar, casilla.select() selecciona lo que escribiste: sigue viéndose, pero en cuanto tecleas algo nuevo se sustituye. Este es el archivo final:

    // 1. Buscamos los elementos de la página
const casilla = document.getElementById("frase");
const botonDecir = document.getElementById("decir");
const respuesta = document.getElementById("respuesta");

// 2. Lee la frase y elige la respuesta
function contestar() {
  const frase = casilla.value.trim();
  const esPregunta = frase.endsWith("?");
  const esGrito = frase === frase.toUpperCase() && frase !== frase.toLowerCase();

  if (frase === "") {
    respuesta.textContent = "Vale, pues nada.";
  } else if (esPregunta && esGrito) {
    respuesta.textContent = "¡Que sí, que ya voy!";
  } else if (esGrito) {
    respuesta.textContent = "¡Relájate!";
  } else if (esPregunta) {
    respuesta.textContent = "Ni idea.";
  } else {
    respuesta.textContent = "Lo que tú digas.";
  }

  casilla.select();
}

// 3. Contesta al pulsar «Decir» o la tecla Enter
botonDecir.addEventListener("click", contestar);

casilla.addEventListener("keydown", function (evento) {
  if (evento.key === "Enter") {
    contestar();
  }
});

    Fíjate en addEventListener("click", contestar): va sin paréntesis. Le damos la función para que la ejecute cuando llegue el click. Con contestar() se ejecutaría una vez al cargar la página y el botón no haría nada.

Retos para quien termine antes

Cada reto se resuelve con lo que ya has usado, más una pieza nueva.

Devuelve el saludo

Nivel 1 · pieza nueva: includes

Si la frase contiene «hola», escrita como sea, que conteste «Ey.». Usa frase.toLowerCase().includes("hola"). ¿En qué lugar de la cadena de if lo pones para que «¿HOLA?» siga siendo una pregunta gritada?

Cambia de cara

Nivel 2 · pieza nueva: cambiar src

Haz una copia de adolescente.svg con otra boca o cejas enfadadas y, cuando le griten, cambia la imagen con imagen.src = "adolescente-enfadado.svg". Vuelve a la imagen normal en el resto de casos.

La conversación entera

Nivel 2 · pieza nueva: createElement y append

Añade una lista vacía al HTML y, en cada turno, crea dos elementos li: uno con lo que dijiste y otro con lo que contestó. Así queda el historial de la charla.

Que no repita siempre lo mismo

Nivel 3 · repasa la bola de cristal

Cambia cada respuesta por un array de respuestas parecidas («Ni idea.», «Yo qué sé.», «Psé.») y elige una al azar con Math.random(), como en la bola de cristal.
